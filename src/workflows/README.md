# n8n Workflows

This directory contains JSON exports of n8n workflows used in the AI Personal Assistant project.

## Workflow Development Process

1. Design and develop workflows in the n8n UI
2. Test functionality thoroughly
3. Export workflow as JSON
4. Store in this directory with appropriate naming
5. Document workflow purpose and functionality in this README

## Workflow Naming Convention

Use descriptive names for workflows:
- `telegram-message-handler.json` - Handles incoming Telegram messages
- `voice-message-processor.json` - Processes voice messages from Telegram
- `rag-query-processor.json` - Processes RAG queries against the vector database
- etc.
