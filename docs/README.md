# Project Documentation

This directory contains documentation for the AI Personal Assistant project.

## Documentation Structure

- `setup.md` - Detailed setup instructions
- `workflows.md` - Documentation for n8n workflows
- `vector-database.md` - Vector database setup and management
- `telegram-bot.md` - Telegram bot setup and configuration
- `development.md` - Development guidelines and best practices
- `deployment.md` - Deployment instructions

## Documentation Guidelines

- Keep documentation up-to-date with code changes
- Use Markdown for all documentation
- Include screenshots or diagrams where helpful
- Provide step-by-step instructions for complex processes
- Document API endpoints and parameters

*Note: Documentation will be added as the project progresses.*
