## Этап первый: Подготовка терема цифрового

### Задание 1: Основа богатырская
- [ ] Настроить n8n на компьютере своём, аки терем на горе высокой
  ```bash
  npm install n8n -g
  mkdir -p ~/.n8n
  touch ~/.n8n/.env
  ```
- [ ] Проверить, что терем стоит крепко
  ```bash
  n8n start
  ```
- [ ] Настроить переменные окружения, аки мебель в тереме расставить
  ```
  N8N_ENCRYPTION_KEY=ключ-шифрования-твой
  N8N_PORT=5678
  N8N_PROTOCOL=http
  N8N_HOST=localhost
  DB_TYPE=sqlite
  DB_PATH=~/.n8n/database.sqlite
  ```

### Задание 2: Выбор базы данных векторной
- [ ] Изучить базы данные векторные, аки купец товары на ярмарке

- [ ] Настроить схему и коллекции, аки полки в сундуке том
- [ ] Проверить, что сундук открывается да закрывается исправно

### Задание 3: Создание гонца телеграмского
