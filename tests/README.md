# Testing

This directory contains test cases and testing utilities for the AI Personal Assistant project.

## Testing Approach

- **Workflow Testing**: Tests for n8n workflows
- **Integration Testing**: Tests for integrations with external services
- **End-to-End Testing**: Complete system tests
- **Performance Testing**: Tests for response time and system load

## Test Structure

- `workflow-tests/` - Tests for individual n8n workflows
- `integration-tests/` - Tests for integrations with external services
- `e2e-tests/` - End-to-end test scenarios
- `performance-tests/` - Performance and load testing

*Test execution instructions will be added as tests are developed.*

## Test Guidelines

- Write tests for all new functionality
- Ensure tests are independent and can run in any order
- Mock external services where appropriate
- Document test coverage and results
